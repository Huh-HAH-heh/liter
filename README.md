# УчМат — учебные материалы

Небольшой репозиторий с учебными конспектами и практическими заданиями. Материалы организованы так, чтобы сначала понять идею, затем увидеть расчёты и только после этого самостоятельно решать задачи.

## Материалы

### Симплекс-метод

**[Открыть лекцию и практику](docs/симплекс-метод-лекция-и-практика.md)**

Внутри:

- интуитивное объяснение линейной оптимизации и истории метода;
- область допустимых решений и идея перехода между вершинами;
- подробная связь элементов симплекс-таблицы с реальной задачей;
- полный расчёт на примере двух продуктов и двух ресурсов;
- алгоритм-шпаргалка, типичные ошибки и задания четырёх уровней;
- ответы для самостоятельной проверки.

## Рекомендуемый порядок изучения

1. Прочитай первую часть, не пытаясь сразу запоминать формулы.
2. Объясни своими словами, зачем нужны целевая функция, ограничения и дополнительные переменные.
3. Разбери расчётную часть с карандашом и бумагой.
4. Реши практические задания до открытия блока с ответами.
5. Вернись к ошибкам и повтори расчёт самостоятельно.

## Публикация на GitHub

В `scripts/publish-to-github.ps1` подготовлен сценарий для публикации репозитория `Huh-HAH-heh/uch-mat`. Он требует установленный GitHub CLI (`gh`) и активную авторизацию через `gh auth login`. По умолчанию репозиторий создаётся **приватным**. Публичный режим можно включить, заменив `--private` на `--public` в сценарии.
